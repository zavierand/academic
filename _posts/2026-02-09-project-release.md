We released our project, [CAPS](https://cap-policy.github.io/#)!By projecting each image into a 3d space, we're able to extract 3d poses of an object in a 2d frame. Using the 3d poses of objects, as well as the visual frames, as input into a [Vector-Quantized Behavior Transformer](https://arxiv.org/abs/2403.03181), we're able to effectively teach robots how to perform simple tasks in environments they've never seen! You can read the [paper here](https://arxiv.org/abs/2602.09017).
